# 商品链接采集工具便携版实施计划

## 目标

交付一个 Windows 64 位便携目录和 ZIP。用户无需安装 Python、Chrome 或驱动，双击 `1688商品采集工具.exe` 即可采集链接，并将登录状态与商品结果保存在便携目录的 `data/` 下。

## 实施步骤

1. 增加统一运行路径模块，分别解析源码根目录、冻结资源目录、便携程序目录、内置浏览器目录和可写数据目录。
2. 调整采集服务及 1688 适配器，使 HTML、资源、Cookie 和浏览器缓存都写入便携 `data/`。
3. 为冻结程序增加隐藏的工作进程入口，使主 EXE 能以子进程形式执行页面采集和资源解析，同时继续提供可取消的实时日志。
4. 调整浏览器启动逻辑，便携模式只使用打包的浏览器与配套驱动；源码模式继续兼容现有开发环境。
5. 增加浏览器组件预检和明确的中文错误，不在便携模式静默使用系统浏览器或联网下载驱动。
6. 增加 PyInstaller 配置与 PowerShell 构建脚本。构建脚本从官方 Chrome for Testing 清单下载同版本浏览器和驱动，校验版本后生成目录包。
7. 写入无用户数据的目录骨架与 `使用说明.txt`，随后生成 ZIP。
8. 增加运行路径、冻结工作进程命令、内置浏览器选择和缺失组件错误的自动化测试。
9. 运行静态检查和完整测试，并从带空格及中文路径启动构建产物。
10. 使用指定的 1688 商品链接进行一次构建产物真实采集，核对 HTML、资源与 `product.json`。

## 完成标准

- 构建过程可通过一条 PowerShell 命令重复执行。
- 发布目录不包含开发环境、历史商品、开发机 Cookie 或缓存。
- EXE 不依赖系统 Python、浏览器或驱动。
- 中文实时日志保持可读。
- 便携目录移动后仍可运行，登录状态和商品结果随 `data/` 一起移动。
- 自动化测试全部通过，真实商品采集成功。

# 商品链接采集工具便携版设计

## 目标

将现有“粘贴商品链接后自动采集”的图形工具打包为 Windows 免安装便携目录。用户解压后双击 EXE 即可使用，不需要安装 Python、pip、Chrome 或浏览器驱动。

首个发布包只包含链接采集功能。平台识别继续使用现有适配器架构，以便后续增加淘宝、京东等平台，而无需修改打包入口或主界面。

## 交付形态

采用 PyInstaller 目录模式，不使用单文件自解压模式。目录模式启动更快，适合携带体积较大的浏览器运行时，也便于检测和替换损坏的组件。

最终生成以下交付物：

- `dist/1688商品采集工具便携版/`
- `dist/1688商品采集工具便携版.zip`

便携目录包含：

```text
1688商品采集工具便携版/
    1688商品采集工具.exe
    browser/        内置浏览器及匹配驱动
    runtime/        Python运行时和第三方依赖
    data/
        browser_data/   登录状态和Cookie
        products/       商品页面、资源和结构化结果
    使用说明.txt
```

`data/` 在首次运行时自动创建。构建产物不携带开发机的 Cookie、缓存或历史商品数据。

## 运行时路径

新增统一的运行路径模块，区分以下位置：

- 程序根目录：EXE 所在的便携目录。
- 只读资源目录：打包后的 Python 依赖及程序资源。
- 浏览器目录：内置浏览器和配套驱动。
- 数据目录：便携目录下的 `data/`。

源码运行和打包运行必须通过同一接口取得这些路径。采集结果、浏览器配置、WebDriver 缓存和其他可变文件不得写入 PyInstaller 内部目录或系统用户目录。

## 浏览器策略

发布包内置一组经过验证、版本匹配的 Chromium 浏览器和驱动。程序固定使用内置浏览器，不检测系统 Chrome，也不在运行时下载驱动。

浏览器使用 `data/browser_data/` 作为用户数据目录，因此登录状态和 Cookie 在程序关闭后保留。复制整个便携目录时，这些数据会一同移动。使用说明必须明确提示该目录可能包含账号登录信息，不应发送给他人。

如果浏览器或驱动缺失、损坏或版本不匹配，程序应显示可理解的中文错误，提示用户重新解压完整发布包，不静默切换到系统浏览器或在线下载其他版本。

## 采集流程

1. 用户粘贴商品链接。
2. 平台注册中心识别链接并移除非必要追踪参数。
3. 采集服务启动内置浏览器并加载便携登录状态。
4. 浏览器打开商品页面；登录或验证码出现时，用户可在可见窗口中处理。
5. 程序保存渲染后的 HTML。
6. 解析标题、价格、SKU、库存、属性、店铺、图片和视频。
7. 下载资源并生成 `product.json`。
8. 界面持续显示 UTF-8 中文日志、阶段进度和结果摘要。
9. 用户可从界面打开对应商品的结果目录。

每个商品的数据保存到 `data/products/<商品ID>/`，相关原始 HTML 保存到 `data/products/` 下。平台适配器不得依赖开发仓库的固定绝对路径。

## 范围

本次包含：

- 商品链接采集 GUI。
- 1688 平台适配器及当前解析、下载、导出流程。
- 内置浏览器和匹配驱动。
- 便携登录状态和商品输出。
- 构建脚本、PyInstaller 配置、ZIP 发布包及使用说明。

本次不包含：

- 原项目旧版综合 GUI。
- 图片编辑器、数据库查看器和批量 HTML 拖放入口。
- 安装程序、系统服务、自动更新器。
- 新电商平台适配器。
- 将用户 Cookie 或历史商品数据预置到发布包。

## 错误处理

- 网络失败、登录拦截或验证码：保留已经生成的文件，显示失败阶段并允许用户重试。
- 磁盘不可写或空间不足：终止当前采集，不覆盖已有商品数据。
- 用户取消：停止当前采集子进程并安全关闭浏览器。
- 浏览器组件不完整：启动采集前检查关键文件并给出中文错误。
- 重复启动采集：保持现有单任务约束，已有任务运行时拒绝第二个任务。
- 程序升级：替换程序文件时默认保留 `data/`，避免清除登录状态和历史结果。

## 构建要求

- 使用可复现的构建脚本生成 PyInstaller 目录包。
- 构建配置显式包含运行时动态导入、数据文件、浏览器和驱动。
- 构建前校验浏览器与驱动版本兼容。
- 构建过程不得把 `.venv`、开发缓存、测试产物、`.git`、`.bug-hunter` 或现有 `products/` 打入发布包。
- 发布 ZIP 的根目录直接包含完整便携目录，解压后无需额外安装步骤。

## 验收标准

- 在未配置 Python、pip、系统 Chrome 和项目环境变量的 Windows 64 位环境中可启动。
- 从中文路径和带空格路径启动均正常。
- 双击 EXE 后出现链接采集界面，无控制台窗口干扰。
- 实时日志中的中文完整可读，不出现乱码或替换字符。
- 内置浏览器能够启动，并使用 `data/browser_data/` 保存和恢复登录状态。
- 使用指定的 1688 商品链接完成一次真实采集。
- 结果目录包含有效 HTML、图片、视频和 `product.json`，界面摘要与文件数量一致。
- 取消任务后不残留由程序启动的浏览器或采集子进程。
- 缺失浏览器关键文件时显示明确错误，而不是崩溃或无限等待。
- 全部自动化测试通过，且增加覆盖打包路径、内置浏览器选择和便携数据目录的测试。
- `使用说明.txt` 说明启动方法、结果位置、登录处理方法以及 Cookie 数据的隐私风险。

## 发布与升级约定

发布包按版本生成新的便携目录和 ZIP。用户升级时复制旧版本的 `data/` 到新版本即可继承登录状态与采集结果。程序代码不得自动删除、迁移或上传 `data/browser_data/` 中的内容。
